This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

VIGA (Vision-as-Inverse-Graphics Agent) is an analysis-by-synthesis code agent for programmatic visual reconstruction. A dual-agent system (Generator + Verifier) iteratively writes scene programs, renders them, and refines based on visual feedback.

## Common Commands

### Environment Setup
```bash
./setup.sh                        # set up all 5 conda environments
./setup.sh sam3d-objects sam3      # set up specific environments only
./setup.sh --check                # verify all environments
```

### Running the Agent
```bash
conda activate viga-agent

# Single task (main entry point)
python main.py --mode <mode> --model <model> \
    --generator-tools tools/blender/exec.py,tools/generator_base.py,tools/initialize_plan.py \
    --verifier-tools tools/blender/investigator.py,tools/verifier_base.py \
    --max-rounds 10

# Batch execution via runner scripts
python runners/static_scene.py --task all --model gpt-4o --max-workers 8
python runners/dynamic_scene.py --task artist --model gpt-5
```

**Modes:** `blendergym`, `blenderbench`, `static_scene`, `dynamic_scene`, `autopresent`

### Evaluation
```bash
conda activate viga-agent
python evaluators/blenderbench/ref_based_eval.py    # reference-based (PL Loss, N-CLIP)
python evaluators/blenderbench/ref_free_eval.py     # reference-free (VLM scoring)
python evaluators/blenderbench/gather.py            # aggregate results
```

## Architecture

### Dual-Agent Loop (`main.py`)

```
Generator (writes code) ──→ Tool execution (renders scene) ──→ Verifier (analyzes output)
     ↑                                                              │
     └──────────────── visual feedback + edit suggestions ──────────┘
```

The Generator calls MCP tools (execute_and_evaluate, get_scene_info, etc.), which render the scene. If `require_verifier=True`, the Verifier analyzes renders and provides feedback. This loop repeats for `--max-rounds` iterations.

### Multi-Environment Tool Dispatch

Different tools require different Python environments. The dispatch mechanism:

1. `setup.sh` generates `utils/_path.py` mapping each tool script to a conda environment
2. `agents/tool_client.py` (`ExternalToolClient`) reads `path_to_cmd` from `_path.py`
3. Each MCP tool server is launched as a subprocess using the correct environment's Python binary
4. Communication happens via MCP over stdio

```
tool_client.py ──stdio──→ /envs/viga-blender/bin/python tools/blender/exec.py
               ──stdio──→ /envs/viga-sam/bin/python tools/sam3d/sam_worker.py
               ──stdio──→ /envs/viga-agent/bin/python tools/generator_base.py
```

### Five Conda Environments

| Environment | Python | Purpose |
|---|---|---|
| `viga-agent` | 3.10 | Main runtime: OpenAI, Anthropic, MCP clients |
| `viga-blender` | 3.11 | Blender 4.2 + Infinigen rendering |
| `viga-sam3d-objects` | 3.11 | SAM-3D, CUDA extensions (diff-gaussian-rasterization, nvdiffrast, gsplat, pytorch3d) |
| `viga-sam` | 3.10 | Segment Anything Model (ViT-H) |
| `viga-sam3` | 3.11 | SAM 3 |

### Key Components

- **`agents/generator.py`** — Code generation agent with sliding-window memory (`--memory-length`)
- **`agents/verifier.py`** — Scene analysis agent with persistent + working memory
- **`agents/tool_client.py`** — MCP client that manages tool server subprocesses via `StdioServerParameters`
- **`tools/blender/exec.py`** — Executes Blender Python scripts via `blender --background -P`
- **`tools/sam3d/init.py`** — Orchestrates SAM segmentation → 3D reconstruction, spawning workers in separate environments
- **`prompts/prompt_manager.py`** — Loads mode-specific, agent-specific, setting-specific prompts
- **`utils/common.py`** — Shared utilities: `build_client()` for multi-vendor LLM support, `tournament_select_best()` for candidate selection, image encoding

### Configuration

- **`utils/_path.py`** — Auto-generated by `setup.sh`. Maps tool script paths → conda environment Python binaries. Override base path via `VIGA_CONDA_BASE` env var.
- **API keys** — Set as environment variables: `OPENAI_API_KEY`, `CLAUDE_API_KEY`, `GEMINI_API_KEY`, `MESHY_API_KEY`
- **Prompts** — Organized by mode under `prompts/` (blendergym, blenderbench, static_scene, dynamic_scene, slidebench)

### Data & Output Layout

```
data/<mode>/<task>/
    target.png, description.txt, assets/

output/<mode>/<timestamp>/<task>/
    generator_memory.json, verifier_memory.json, renders/, scripts/
```
